그 순간 프로젝트 전체의 스냅샷을 저장 함.
.git/objects
  > blob   : 파일의 내용, 파일 이름, 경로, 권한도 들어 있지 않습니다. 오직 바이트 덩어리
  > tree   : 디렉토리 하나. 이름 + 권한 + 해시 목록이며, 각 항목은 blob(파일)이거나 다른 tree(하위 디렉토리)를 가리킵니다.
  > commit : 최상위 tree 하나 + 부모 커밋(0개는 최초 커밋, 2개 이상은 병합 커밋) + 작성자 / 커미터 / 시가 + 메시지
  > tag.   : 특정 객체에 붙는 이름표, 메시지와 서명을 담을 수 있다.

핵심워크 플로우

working directory 내책상(작업공간)
-- 매일 반복하는 3박자 로틴 (add, commit, push) --

git add . -- 수정파일 -> 장바구니
git commit -m "feat: 어쩌구저쩌구..."   --- 박스밀봉 + 메모
git push origin main.  --- 클라우드로 배송 : 로컬 박스를 Github 금고로 업로드

.gitignore -- 무시목록의 마법

git reset
